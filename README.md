# 파판14 제작 수익 분석 (초코보)

거래소 시세(Universalis)와 게임 레시피 데이터를 조합해서, **지금 만들어 팔면 남는 제작품**을 순위별로 보여주는 웹페이지입니다.
데이터를 조회하고 분석만 합니다. 게임에는 전혀 손대지 않아요.

## 새 사이트 (Cloudflare Pages) — 빠른 버전
서버 없이 **미리 계산해 둔 결과를 보여주는** 사이트입니다. 클릭할 때 서버를 거치지 않아서 바로 반응하고, 잠들지도 않습니다.

- **GitHub Actions** (`.github/workflows/site.yml`) 가 매시간 시세를 받아 계산하고 (`python -m ffxiv.build`), 결과를 **Cloudflare Pages** 에 올립니다.
- 화면: `web/` (사이드바·필터·계산) + `ffxiv/design/dashboard.*` (표·상세, Streamlit 판과 같이 씀)
- 필터·판매 도시(세율)·분류는 브라우저에서 바로 계산합니다. 판매 품질(NQ/HQ/통합)은 세 벌 미리 계산해 둡니다.
- 중간재료 직접 제작 여부는 `config.yaml` 의 `job_levels` 기준으로 미리 계산됩니다 (사이트의 직업 레벨은 순위에서 거르는 데만 씀).
- 지금 바로 갱신: GitHub 저장소 **Actions → 사이트 갱신 → Run workflow**
- 내 PC 에서 확인: `python -m ffxiv.build` (시세 받기까지) 또는 `python -m ffxiv.build --no-fetch` (저장된 시세로 계산만) → `cd site && python -m http.server` → http://localhost:8000

### 처음 한 번 설정
1. Cloudflare 가입 → **API 토큰**(Account · Cloudflare Pages · Edit 권한)과 **Account ID** 준비
2. GitHub 저장소 **Settings → Secrets and variables → Actions** 에 `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` 추가
3. **Actions → 사이트 갱신 → Run workflow** → 끝나면 https://don-duruwa.pages.dev
4. 로그인 걸기: Cloudflare **Zero Trust → Access → Applications → Add (Self-hosted)** → 도메인 `don-duruwa.pages.dev` → 허용할 이메일 등록

## 화면 사용법
- **⚒ 제작 / ⛏ 채집**: 사이드바 맨 위에서 페이지를 고릅니다. 시세·테마·판매 설정(품질, 판매 도시)은 두 페이지가 같이 씁니다.
- **⛏ 채집 페이지**: 광부·원예가로 캘 수 있는 거래소 판매 가능 아이템을 순위로 봅니다. 재료비가 없으니 순수익 = 판매가 × (1 − 판매세)이고, 기본 정렬은 **하루 잠재 이익**(개당 순수익 × 하루 판매량)입니다.
  채집 레벨 범위·광부/원예가 레벨로 거르고, 분류는 일반 / ⏰ 시간 한정(미지·전설 등 정해진 시간에만 열리는 채집지) / 💎 크리스탈입니다. 낚시는 아직 없습니다.
- **다크 / 화이트** 와 **색감**(초록·골드·크리스탈·에테르·로즈·실버)은 사이드바 맨 위에서 고릅니다. 처음엔 화이트 + 초록으로 열립니다. 주소에 기억돼서 즐겨찾기하면 그대로 열립니다.
- **🔄 데이터 갱신**: 시세를 새로 받습니다. 누르지 않아도 페이지를 열 때 마지막 갱신이 60분 넘었으면 자동으로 받습니다.
  받는 건 **뒤에서** 돌아서(모든 제작품 약 11,000개 ≈ 5~10분) 그동안에도 화면은 저장된 시세로 계속 볼 수 있고, 진행 상황은 사이드바에 나옵니다. 다 받으면 화면이 자동으로 새 시세로 바뀝니다.
  시세는 모든 제작품·모든 레벨을 받아두기 때문에 분류나 레벨을 바꿔도 다시 받지 않습니다.
- **판매 품질** (사이드바): HQ 가 있는 템을 **NQ / HQ / 통합**(NQ·HQ 섞어서) 중 어느 시세로 팔지 고릅니다. 고른 품질로 팔린 기록이 없으면 계산 불가로 빠지고, 다른 품질로는 몇 건 팔렸는지 알려줍니다.
- **📦 잘 팔리는 묶음**: 여러 개 겹치는 아이템은 재료 상세에 묶음 크기(1개, 2~5개, 6~10개 …)별 판매 건수·팔린 수량·개당 중앙값·지금 매물 수가 나옵니다. 제일 자주 팔린 묶음은 표에 📦 뱃지로 표시됩니다.
- **🛒 장보기**: 표 왼쪽 **+** 로 담으면 오른쪽 아래에 🛒 버튼이 뜹니다. 누르면 오른쪽 서랍에 재료가 **구매 서버별**로 묶여 나오고, 열어둔 채로 계속 담을 수 있습니다 (Esc 로 닫기).
  재료마다 체크박스로 산 걸 표시(취소선)하고, 목록을 이름 붙여 저장·불러오기(브라우저에 저장), 텍스트 파일로 받기·복사를 할 수 있습니다. 아이템마다 제작 횟수를 바꿀 수 있고, 담은 건 브라우저에 기억됩니다.
- **판매 소요**: 내 가격 이하 매물 + 내 1개가 팔리는 데 걸리는 대략의 날 수 (하루 판매량 기준). 사이드바에서 최대 일수로 거를 수 있습니다.
- **재료 상세**: 7일 시세 추이(판매가·판매 수량) 그래프와, HQ 가 있는 아이템은 NQ/HQ 로 팔 때 이익 비교가 같이 나옵니다.
- **서버 선택**: 화면 위 **통합 / 카벙클 / 초코보 / 모그리 / 톤베리 / 펜리르** 로 순위를 바꿔 봅니다. 통합은 5개 서버 판매를 합친 중앙값 순위, 서버를 고르면 그 서버 시세로 매긴 순위입니다. 그 아래에서 분류·직업을 고릅니다.
- **서버별 판매 비교**: 재료 상세에서 5개 서버 각각의 판매가·순수익을 비교합니다 (👑 = 판매 2건 이상 중 제일 많이 남는 곳). 다른 서버에 올리려면 그 서버에 리테이너가 있는 캐릭터가 필요합니다.
- **뱃지** (마우스 올리면 설명): 🔥 덤핑 경쟁(최저가와 2번째 매물 차이 2% 미만), 📉 하락 중(최근 2일 가격이 그 전보다 10%↓), ✨ 다른 품질로 팔면 더 남음, ❗ 이상 거래 포착(그 서버 중앙값과 3배 넘게 차이 나는 거래를 빼고 계산 — `odd_sale_ratio`), ⚠ 근거 약함, 🔻 HQ 매물가로 깎음
- **업데이트 내역**: 사이드바 맨 아래에 버전·일시·변경 내용이 나옵니다 (`ffxiv/changelog.py`).
- **분류**: 화면 위 **전체 / 🪑 가구 / ⚔ 장비 / 🧱 재료 / 🍲 소모품 / ✨ 기타** 로 나눠 보거나 합쳐서 봅니다. 장비는 **장비 전체**로 보거나 무기·도구·방어구·액세서리로 한 번 더 나눌 수 있습니다 (기준은 `config.yaml` 의 `item_groups`). 요약 카드·직업 탭·계산 불가 목록도 고른 분류에 맞춰 바뀝니다.
- **탭**: 통합 순위 / 직업별
- **표**: 컬럼 제목을 클릭하면 정렬되고(한 번 더 누르면 반대로), 행을 클릭하면 아래에 **재료 상세**(구매처, 단가, 거래량, 구매 서버)가 나옵니다.
- **아이템명 앞 ★**: 별 레시피. 레벨만 되고 능력치가 모자라면 못 만들 수 있어요.
- **기타 칸**: 비전서 필요, 퀘스트 해금, HQ/NQ 기준, ⚠ 데이터 오래됨 표시
- **하루 잠재 이익**: 순수익 × 시장 전체의 하루 판매량. 내가 그만큼 다 판다는 뜻이 아니라 "이 아이템 시장이 얼마나 큰지"를 보는 값입니다.
- 맨 아래 **"계산할 수 없었던 레시피"** 에서 판매 기록이나 재료 시세가 없어 빠진 것들을 확인할 수 있습니다.

## 설정 (`config.yaml`)
메모장으로 열어서 고치고 웹페이지를 새로고침(F5)하면 됩니다.

| 항목 | 설명 |
|---|---|
| `world` | 서버 이름 (기본 `초코보`) |
| `buy_scope` | 재료 구매를 데이터센터 전체(`dc`)에서 할지, 내 서버만(`world`)에서 할지 |
| `job_levels` | 직업별 제작 레벨 기본값 (사이드바 "직업별 레벨"에서도 변경 가능). 이보다 높은 레시피는 빠지고, 중간재료 직접 제작도 이 레벨까지만 고려 |
| `recipe_level_min/max` | 레시피 레벨 범위 기본값 (사이드바에서도 변경 가능) |
| `tax_city` | 내 리테이너가 파는 도시 (판매세). `min` 이면 가장 싼 도시 |
| `batch_size` | 한 번에 몇 번 만들지. 재료를 싼 매물부터 이만큼 사는 비용으로 원가 계산 |
| `filters` | 사이드바 필터의 기본값 |
| `self_gathered_items` | 직접 채집해서 원가 0 으로 칠 재료 이름 목록 |
| `allow_secret_recipe_intermediates` | 비전서가 있다면 `true` 로 — 비전서 레시피로 중간재료를 만드는 경로도 고려 |

## 계산 방식
- **서버 범위**
  - 판매: 시세는 항상 한국 5개 서버 전체를 받아서 **통합 순위**와 **서버별 순위**를 같이 계산
  - 재료: 다른 서버에 가서 제일 싼 매물을 사 온다고 가정. 재료 상세의 "구매 서버"에 어디로 가면 되는지 표시
- **이상 거래·미끼 매물은 서버마다 따로** 판단 (서버마다 시세 수준이 달라서)
  - 그 서버 판매 중앙값과 3배 넘게 차이 나는 거래는 이상 거래로 빼고 계산
  - 그 서버 중앙값의 50% 미만인 등록가는 미끼 매물로 보고 무시
- **판매 예상가**
  - 통합: 서버별로 거른 최근 7일 판매를 모은 중앙값 (NQ 는 HQ 중앙값보다 비싸게 안 잡음)
  - 서버별: min(그 서버 판매 중앙값, 그 서버 최저 등록가) (NQ 는 그 서버 HQ 최저가보다 비싸게 안 잡음)
  - 판매 기록이 없으면 계산하지 않음
- **재료 단가** = 가장 싼 방법 하나
  - 거래소: 싼 매물부터 필요 수량만큼 산 평균 단가 × 1.05 (구매세)
  - NPC 상점: 상점가 (퀘스트·업적 조건 없는 길 상점만)
  - 직접 제작: 하위 재료까지 같은 방식으로 계산 (내 레벨로 가능하고 별이 없는 레시피만)
- **개당 원가** = 재료비 합 ÷ 레시피 결과물 개수 (크리스탈/샤드 포함)
- **순수익** = 판매 예상가 × (1 − 판매세) − 개당 원가
- **수익률** = 순수익 ÷ 개당 원가
- **재료 원활성 필터**: 거래소에서 사는 재료마다 (7일 판매 수량 ÷ 필요 수량)을 구해서 가장 작은 값이 기준 이상이어야 통과

## 단계별 확인용 명령어
웹페이지 없이 각 단계 결과만 확인하고 싶을 때:
```
python -m ffxiv.gamedata   # 1단계: 분석 대상 레시피 목록
python -m ffxiv.market     # 2단계: 시세 받아서 cache/ 에 저장 (전체 레벨)
python -m ffxiv.profit     # 3단계: 상위 15개 + 원가 내역
```

## 알아둘 점
- 한국 서버 시세는 플레이어가 업로드한 만큼만 쌓입니다. 결과가 너무 적으면 사이드바 필터를 완화해 보세요.
- NPC 상점 데이터에는 실제로는 못 가는 상점이 섞여 있을 수 있어요. 이상한 NPC 가격이 보이면 `npc_ignore_items` 에 재료 이름을 넣으면 됩니다.
