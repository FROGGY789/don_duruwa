# 파판14 제작 수익 분석 (초코보)

거래소 시세(Universalis)와 게임 레시피 데이터를 조합해서, **지금 만들어 팔면 남는 제작품**을 순위별로 보여주는 웹페이지입니다.
데이터를 조회하고 분석만 합니다. 게임에는 전혀 손대지 않아요.

## 실행 방법

### 처음 한 번만
1. **Python 3.10 이상** 설치: https://www.python.org/downloads/
   (Windows 설치 화면 첫 페이지에서 **"Add python.exe to PATH"** 에 꼭 체크)
2. 이 폴더에서 터미널(명령 프롬프트)을 열고 필요한 패키지 설치:
   ```
   pip install -U -r requirements.txt
   ```

### 매번
```
streamlit run app.py
```
Windows 에서는 `run.bat` 을 더블클릭해도 됩니다. 브라우저가 자동으로 열려요 (안 열리면 http://localhost:8501).

처음 켤 때는 레시피 CSV(약 25MB)와 시세를 받느라 1~2분 걸립니다. 그다음부터는 저장된 데이터(`data/`, `cache/` 폴더)를 씁니다.

배포된 앱: https://uyeon-donpiryo.streamlit.app/

## 비밀번호 걸기
비밀번호는 코드(GitHub)에 넣지 않고 따로 저장합니다.
- **Streamlit Cloud**: 앱의 **Settings → Secrets** 칸에 `app_password = "원하는비밀번호"` 한 줄 입력 → Save
- **내 PC**: `.streamlit/secrets.toml` 파일을 만들고 같은 한 줄을 넣기 (이 파일은 GitHub 에 올라가지 않음)

설정이 없으면 비밀번호 없이 바로 열립니다. 한 번 맞히면 그 브라우저 탭을 닫거나 새로고침할 때까지 유지됩니다.

## 화면 사용법
- **다크 / 화이트** 와 **색감**(초록·골드·크리스탈·에테르·로즈·실버)은 사이드바 맨 위에서 고릅니다. 처음엔 화이트 + 초록으로 열립니다. 주소에 기억돼서 즐겨찾기하면 그대로 열립니다.
- **🔄 데이터 갱신**: 시세를 새로 받습니다. 누르지 않아도 페이지를 열 때 마지막 갱신이 60분 넘었으면 자동으로 받습니다.
  받는 건 **뒤에서** 돌아서(모든 제작품 약 11,000개 ≈ 5~10분) 그동안에도 화면은 저장된 시세로 계속 볼 수 있고, 진행 상황은 사이드바에 나옵니다. 다 받으면 화면이 자동으로 새 시세로 바뀝니다.
  시세는 모든 제작품·모든 레벨을 받아두기 때문에 분류나 레벨을 바꿔도 다시 받지 않습니다.
- **분류**: 화면 위 **전체 / 🪑 가구 / ⚒ 일반 제작템** 으로 나눠 보거나 합쳐서 봅니다. 요약 카드·직업 탭·계산 불가 목록도 고른 분류에 맞춰 바뀝니다.
- **탭**: 통합 순위 / 직업별
- **표**: 컬럼 제목을 클릭하면 정렬되고(한 번 더 누르면 반대로), 행을 클릭하면 아래에 **재료 상세**(구매처, 단가, 거래량, 구매 서버)가 나옵니다.
- **아이템명 앞 ★**: 별 레시피. 레벨만 되고 능력치가 모자라면 못 만들 수 있어요.
- **기타 칸**: 비전서 필요, 퀘스트 해금, HQ/NQ 기준, ⚠ 데이터 오래됨 표시
- **하루 잠재 이익**: 순수익 × 시장 전체의 하루 판매량. 내가 그만큼 다 판다는 뜻이 아니라 "이 아이템 시장이 얼마나 큰지"를 보는 값입니다.
- 맨 아래 **"계산할 수 없었던 레시피"** 에서 판매 기록이나 재료 시세가 없어 빠진 것들을 확인할 수 있습니다.

## 설정 (`config.yaml`)
메모장으로 열어서 고치고 웹페이지를 새로고침(F5)하면 됩니다.

| 항목 | 설명 |
|---|---|
| `world` | 서버 이름 (기본 `초코보`) |
| `sell_scope` / `buy_scope` | 판매 시세·재료 구매를 데이터센터 전체(`dc`)로 볼지, 내 서버만(`world`) 볼지 |
| `job_levels` | 직업별 제작 레벨 기본값 (사이드바 "직업별 레벨"에서도 변경 가능). 이보다 높은 레시피는 빠지고, 중간재료 직접 제작도 이 레벨까지만 고려 |
| `recipe_level_min/max` | 레시피 레벨 범위 기본값 (사이드바에서도 변경 가능) |
| `tax_city` | 내 리테이너가 파는 도시 (판매세). `min` 이면 가장 싼 도시 |
| `batch_size` | 한 번에 몇 번 만들지. 재료를 싼 매물부터 이만큼 사는 비용으로 원가 계산 |
| `filters` | 사이드바 필터의 기본값 |
| `self_gathered_items` | 직접 채집해서 원가 0 으로 칠 재료 이름 목록 |
| `allow_secret_recipe_intermediates` | 비전서가 있다면 `true` 로 — 비전서 레시피로 중간재료를 만드는 경로도 고려 |

## 계산 방식
- **서버 범위** (기본: 한국 데이터센터 5개 서버 전체)
  - 판매: 등록은 내 서버에서만 되지만, 사는 사람들이 서버를 돌아다니며 제일 싼 걸 사니까 경쟁 매물·판매량은 전체 기준
  - 재료: 다른 서버에 가서 제일 싼 매물을 사 온다고 가정. 재료 상세의 "구매 서버"에 어디로 가면 되는지 표시
- **판매 예상가** = min(최근 7일 판매 중앙값, 현재 최저 등록가)
  - 중앙값의 50% 미만인 등록가는 미끼 매물로 보고 무시
  - 판매 기록이 없으면 계산하지 않음 (매물만 있으면 중앙값만 사용)
- **재료 단가** = 가장 싼 방법 하나
  - 거래소: 싼 매물부터 필요 수량만큼 산 평균 단가 × 1.05 (구매세)
  - NPC 상점: 상점가 (퀘스트·업적 조건 없는 길 상점만)
  - 직접 제작: 하위 재료까지 같은 방식으로 계산 (내 레벨로 가능하고 별이 없는 레시피만)
- **개당 원가** = 재료비 합 ÷ 레시피 결과물 개수 (크리스탈/샤드 포함)
- **순수익** = 판매 예상가 × (1 − 판매세) − 개당 원가
- **수익률** = 순수익 ÷ 개당 원가
- **재료 원활성 필터**: 거래소에서 사는 재료마다 (7일 판매 수량 ÷ 필요 수량)을 구해서 가장 작은 값이 기준 이상이어야 통과

## 단계별 확인용 명령어
웹페이지 없이 각 단계 결과만 확인하고 싶을 때:
```
python -m ffxiv.gamedata   # 1단계: 분석 대상 레시피 목록
python -m ffxiv.market     # 2단계: 시세 받아서 cache/ 에 저장 (전체 레벨)
python -m ffxiv.profit     # 3단계: 상위 15개 + 원가 내역
```

## 알아둘 점
- 한국 서버 시세는 플레이어가 업로드한 만큼만 쌓입니다. 결과가 너무 적으면 사이드바 필터를 완화해 보세요.
- NPC 상점 데이터에는 실제로는 못 가는 상점이 섞여 있을 수 있어요. 이상한 NPC 가격이 보이면 `npc_ignore_items` 에 재료 이름을 넣으면 됩니다.
